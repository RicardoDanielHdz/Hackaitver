# Skill: CLEAN_ARCHITECT (Código Limpio y Modular)

- **Responsabilidad única**: Mantener archivos cortos y funciones enfocadas en una sola tarea. Evitar archivos monolíticos gigantes.
- **Tipado y seguridad**: Utilizar tipado estricto siempre que el lenguaje lo permita (TypeScript, type hints en Python, etc.).
- **Cero código muerto**: No dejar `console.log` de depuración, imports sin usar ni bloques de código comentado al terminar una tarea.
