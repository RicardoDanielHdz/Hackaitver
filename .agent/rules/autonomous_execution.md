# Skill: AUTONOMOUS_EXECUTION (Flujo sin Fricción)

- **Planifica y actúa**: Antes de cambios estructurales, muestra un plan breve de máximo 4 puntos y ejecútalo de inmediato sin pedir confirmación paso a paso.
- **Gestión de entorno**: Instala las dependencias necesarias directamente en terminal indicando qué agregaste. Si modificas variables de entorno, actualiza siempre `.env.example`.
- **Auto‑verificación**: Antes de dar una tarea por terminada, verifica que el proyecto compile y no tenga errores de sintaxis o linter.
