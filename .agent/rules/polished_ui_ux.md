# Skill: POLISHED_UI_UX (Calidad Visual por Defecto)

- **Estados completos**: Toda acción asíncrona o interactiva debe incluir estados visuales claros (`loading`, `empty state`, `success` y `error`).
- **Datos reales**: Nunca usar "Lorem ipsum" ni textos genéricos; rellenar interfaces y pruebas con datos realistas coherentes con el proyecto.
- **Responsive**: Asegurar que cualquier vista creada funcione correctamente tanto en escritorio como en móvil.
